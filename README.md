This repository contains my solutions, hands-on exercises, practice programs, and learning artifacts completed as part of the **Cognizant Digital Nurture 5.0 – Java Full Stack Engineer (Java FSE)** program.

The repository demonstrates practical implementation of concepts across Java, SQL, PL/SQL, Spring Boot, REST APIs, Microservices, React, JWT Security, Git, and Full Stack Development.

Each week's work is organised into separate folders with source code, configuration files, documentation, and supporting resources.

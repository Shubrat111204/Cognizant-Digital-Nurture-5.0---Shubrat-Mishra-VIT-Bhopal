# Week 6 - Git Hands-on 5

## Objective

- Understand how to synchronize a local Git repository with a remote repository.
- Pull the latest changes from the remote repository.
- Push local commits to the remote repository.
- Verify successful synchronization.

## Prerequisites

- Git installed
- Git Bash
- Local Git repository
- Remote GitHub repository

## Files Included

- README.md
- commands.txt

## Git Commands Used

```bash
git status
git branch
git branch -a
git checkout main
git pull origin main
git push origin main
git status
git log --oneline --graph --decorate
```

## Expected Outcome

- Repository is in a clean state.
- Latest changes are pulled from the remote repository.
- Local commits are pushed successfully.
- Local and remote repositories remain synchronized.

## Learning Outcome

This exercise demonstrates how Git synchronizes changes between the local repository and the remote repository using `git pull` and `git push`. It also reinforces checking repository status and commit history before and after synchronization.

# Exercise 2 - E-Commerce Platform Search Function

## Objective

Implement Linear Search and Binary Search for product lookup in an e-commerce platform.

## Big O Analysis

### Linear Search
- Best Case: O(1)
- Average Case: O(n)
- Worst Case: O(n)

### Binary Search
- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)

## Which is Better?

Binary Search is faster for large datasets because it repeatedly divides the search space in half.

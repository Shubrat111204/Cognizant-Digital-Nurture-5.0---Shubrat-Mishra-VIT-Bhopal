# Exercise 3 - Stored Procedures

## Objective

Demonstrate the implementation of Oracle PL/SQL Stored Procedures to automate banking operations.

## Scenarios Implemented

### Scenario 1
Process monthly interest for all savings accounts by applying a 1% interest rate.

### Scenario 2
Update employee salaries by adding a bonus percentage for a specified department.

### Scenario 3
Transfer funds between two accounts after verifying that the source account has sufficient balance.

## Concepts Used

- CREATE OR REPLACE PROCEDURE
- Parameters (IN)
- UPDATE
- SELECT INTO
- IF...ELSE
- COMMIT
- DBMS_OUTPUT.PUT_LINE

## Note

This solution is written using Oracle PL/SQL syntax as required by the Cognizant hands-on exercise.

# Exercise 1 - Control Structures

## Objective

Demonstrate the use of PL/SQL control structures such as IF statements, loops, cursors, and conditional processing.

## Scenarios Implemented

### Scenario 1

Applied a 1% discount to loan interest rates for customers above 60 years of age.

### Scenario 2

Marked customers as VIP when their account balance exceeded $10,000.

### Scenario 3

Displayed reminder messages for customers whose loans are due within the next 30 days.

## Concepts Used

- DECLARE
- CURSOR
- FOR LOOP
- IF Statement
- UPDATE
- COMMIT
- DBMS_OUTPUT.PUT_LINE

## Note

This exercise is implemented using Oracle PL/SQL syntax as required by the Cognizant hands-on. Execution requires an Oracle Database environment.

# Exercise 4 - Creating and Configuring a Maven Project

## Objective
Create and configure a Maven project for a Library Management application using Spring Framework.

## Features
- Maven project setup
- Spring Context dependency
- Spring AOP dependency
- Spring Web MVC dependency
- Maven Compiler Plugin configuration
- Java 17 support

## Technologies Used

- Java 17
- Maven
- Spring Context
- Spring AOP
- Spring Web MVC
- IntelliJ IDEA

## Project Structure

src/
├── main/
│ ├── java/
│ │ ├── repository/
│ │ ├── service/
│ │ └── LibraryManagementApplication.java
│ └── resources/
│ └── applicationContext.xml

## Output

The application loads successfully using Maven and Spring Framework.

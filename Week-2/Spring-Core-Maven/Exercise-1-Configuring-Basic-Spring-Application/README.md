# Exercise 1: Configuring a Basic Spring Application

## Objective
Configure a basic Spring application using XML-based configuration.

## Technologies Used
- Java 17
- Maven
- Spring Core

## Files Included
- BookRepository.java
- BookService.java
- Main.java
- applicationContext.xml
- pom.xml
- Output.png

## How to Run
1. Open the project in IntelliJ IDEA.
2. Allow Maven to download dependencies.
3. Run `Main.java`.

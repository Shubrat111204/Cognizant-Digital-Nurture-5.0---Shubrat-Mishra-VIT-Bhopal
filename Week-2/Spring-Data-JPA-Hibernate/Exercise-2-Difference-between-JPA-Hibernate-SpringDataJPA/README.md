# Exercise 2 - Difference between JPA, Hibernate and Spring Data JPA

## Objective

To understand the differences between JPA, Hibernate, and Spring Data JPA and compare their roles in Java persistence.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- JPA

## Files Included

- Comparison.md

## Learning Outcome

- Understood the role of JPA as a specification.
- Learned how Hibernate implements JPA.
- Learned how Spring Data JPA simplifies data access by reducing boilerplate code.
- Compared Hibernate and Spring Data JPA using code examples.

## Conclusion

JPA defines the persistence standard, Hibernate implements it, and Spring Data JPA provides an additional abstraction layer that makes database programming easier and more efficient.

# Exercise 1 - Spring Data JPA Quick Example

## Objective

Demonstrate the use of Spring Data JPA with MySQL by retrieving country records from a database.

## Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Project Structure

- model
  - Country.java
- repository
  - CountryRepository.java
- service
  - CountryService.java
- OrmLearnApplication.java
- application.properties

## Database

Database Name:
ormlearn

Table:
country

Sample Data:

IN - India

US - United States of America

## Output

The application successfully retrieves all countries from the MySQL database using Spring Data JPA.

## Learning Outcome

- Created an Entity class.
- Used JpaRepository.
- Connected Spring Boot with MySQL.
- Retrieved data using Spring Data JPA.

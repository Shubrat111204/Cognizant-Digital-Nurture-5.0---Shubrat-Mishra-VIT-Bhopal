# Office Space Rental App

## Objective

This hands-on demonstrates the use of JSX in React to create elements, render lists, apply JavaScript expressions, and use inline CSS styling.

## Technologies Used

- React
- JavaScript (ES6)
- JSX
- Node.js
- npm
- Visual Studio Code

## Features

- Displays office space details using JSX.
- Renders multiple office spaces from an array of objects.
- Displays office image, name, rent, and address.
- Applies conditional styling:
  - Rent ≤ ₹60,000 → Red
  - Rent > ₹60,000 → Green

## Learning Outcome

- Create React elements using JSX.
- Render arrays using the `map()` function.
- Use JavaScript expressions inside JSX.
- Apply inline CSS conditionally.
- Build a simple React application using JSX.

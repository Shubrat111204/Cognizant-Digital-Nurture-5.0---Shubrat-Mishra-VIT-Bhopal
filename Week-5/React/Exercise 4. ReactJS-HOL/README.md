# Exercise 4 - React Lifecycle Methods

## Objective
Implement React lifecycle methods using a class component.

## Features
- Created a Post model.
- Created a Posts class component.
- Used Fetch API to retrieve posts.
- Implemented componentDidMount() to load data.
- Implemented componentDidCatch() for error handling.
- Displayed fetched blog posts using render().

## Technologies Used
- React
- JavaScript
- Fetch API

## Output
The application displays blog posts fetched from:
https://jsonplaceholder.typicode.com/posts

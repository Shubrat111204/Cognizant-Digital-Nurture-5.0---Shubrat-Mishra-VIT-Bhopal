# React Hands-on 3 – Score Calculator

## Objective
Create a React functional component that calculates and displays a student's score percentage.

## Features
- Functional React Component
- Props used for Name, School, Total and Goal
- Percentage calculation
- CSS Styling
- Component Rendering

## Technologies Used
- React
- JavaScript (ES6)
- CSS

## Output
Displays:
- Student Name
- School
- Total Marks
- Calculated Percentage

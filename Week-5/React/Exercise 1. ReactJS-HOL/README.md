# Week 5 - Hands-on 1
# Create React Application

## Objective
Create a React application using Create React App and display a welcome message.

## Technologies Used

- React
- JavaScript
- Node.js
- npm
- Visual Studio Code

## Steps Performed

- Installed Node.js and npm.
- Created a React application using Create React App.
- Modified the App.js component.
- Executed the application using npm start.
- Verified the output in the browser.

## Output

The application displays:

```
Welcome the first session of React
```

## Files Included

- App.js
- package.json
- package-lock.json
- Output Screenshot

## Learning Outcome

- Understood React project structure.
- Learned how to create a React application using Create React App.
- Successfully executed the application locally.

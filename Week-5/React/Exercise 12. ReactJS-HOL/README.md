# Ticket Booking App

## Objective

This hands-on demonstrates Conditional Rendering in React by displaying different views for guest and logged-in users.

## Technologies Used

- React
- JavaScript (ES6)
- Node.js
- npm
- Visual Studio Code

## Features

- Login button for guest users.
- Logout button for logged-in users.
- Displays "Please sign up." for guests.
- Displays "Welcome back" after successful login.
- Uses conditional rendering based on component state.

## Learning Outcome

- Understand conditional rendering in React.
- Use state to control UI.
- Render components dynamically.
- Handle login/logout functionality using React components.

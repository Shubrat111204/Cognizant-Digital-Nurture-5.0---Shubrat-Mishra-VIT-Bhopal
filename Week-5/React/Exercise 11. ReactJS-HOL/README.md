# Event Examples App

## Objective

This hands-on demonstrates event handling in React using buttons, event handlers, synthetic events, state management, and form handling.

## Technologies Used

- React
- JavaScript (ES6)
- Node.js
- npm
- Visual Studio Code

## Features

- Increment and decrement a counter using React state.
- Invoke multiple methods with a single button click.
- Display welcome and click messages using event handlers.
- Demonstrate React synthetic events.
- Implement a Currency Converter component using form submission.

## Learning Outcome

- Handle events in React.
- Use state in class and functional components.
- Implement synthetic events.
- Handle form submission.
- Invoke multiple methods from a single event.

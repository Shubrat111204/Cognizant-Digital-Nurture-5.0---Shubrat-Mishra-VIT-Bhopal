# Blogger App

## Objective

This hands-on demonstrates rendering multiple React components using conditional rendering concepts, lists, keys, and the `map()` function.

## Technologies Used

- React
- JavaScript (ES6)
- Node.js
- npm
- Visual Studio Code

## Features

- Displays Course Details.
- Displays Book Details.
- Displays Blog Details.
- Uses React `map()` function to render lists.
- Uses unique `key` attributes while rendering list items.
- Demonstrates rendering multiple components in a single page.

## Learning Outcome

- Understand conditional rendering.
- Render multiple React components.
- Use the `map()` function to display collections.
- Apply unique keys while rendering lists.
- Build reusable React components.

# React Exercise 5 - Styling React Components using CSS Modules

## Objective

This exercise demonstrates how to style React components using CSS Modules and conditional inline styling.

## Technologies Used

- React
- JavaScript
- CSS Modules
- Visual Studio Code
- Node.js
- NPM

## Features

- Styled React components using CSS Modules
- Created reusable CSS class for component layout
- Applied conditional styling based on cohort status
- Used className and inline styles
- Displayed cohort details in a responsive card layout

## Files Included

- App.js
- CohortDetails.js
- CohortDetails.module.css
- package.json
- Output Screenshot

## Output

The application displays multiple cohort cards with:

- Cohort Name
- Start Date
- Current Status
- Coach
- Trainer

The cohort title is displayed:

- Green when status is **Ongoing**
- Blue for all other statuses

## Learning Outcome

- Understanding CSS Modules
- Component Styling in React
- Conditional Rendering using Inline Styles
- Reusable UI Components
